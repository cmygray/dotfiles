# draw — 말 대신 예시 그림

그림의 목적은 장식이 아니라 **구체화 강제**입니다. 추상어로는 그릴 수 없으니 실제 문장·URL·값을 넣게 되고, 그 과정에서 틀린 주장이 드러납니다. 그리다가 실제 사례를 채울 수 없으면 그리기를 멈추고 주장부터 다시 봅니다.

## 1. 먼저 가르기: 그림인가, 줄글인가

| 혼란의 원인 | 답 |
|---|---|
| 약어·내부 번호([13], M7b)·지어낸 용어 | 그리지 않습니다. 사용자 낱말로 줄글을 다시 씁니다 |
| 결정 항목이 많음 | 그리지 않습니다. 지금 정할 것만 남깁니다 |
| 추상 지표만 있고 사례가 없음 | 실제 사례 1~2건을 나란히. 표로 충분하면 표 |
| 아래 다섯 종류 | 그립니다 |

그림이 통하는 다섯 종류:
1. **화면 vs 내부**: 사용자가 화면에서 보는 것과 데이터·프롬프트·저장값을 오가는 설명. 화면 목업 옆에 내부를 둡니다. 화면에 없는 것(버튼, 상세 화면)은 그리지 않아 "없다"가 보이게 합니다.
2. **원문 위의 위치**: 원문을 그대로 두고 해당 구절에 강조를 칩니다.
3. **같은 사례 대조**: 정답 vs 모델, 전 vs 후, 안 A vs 안 B. 같은 입력을 좌우에 놓습니다.
4. **경로·순서**: 리디렉트, 요청 흐름. 실제 URL·상태 코드를 씁니다.
5. **예산·분포**: 시간·비용·점수. 실제 수치를 막대로. 합계를 그림에서 다시 계산해 봅니다.

## 2. 그리기 규칙

- 한 응답에 1장. 그림 위에 결론 한 줄을 크게 씁니다(예: "현재 PDF가 바로 열림. 상세 화면 없음").
- 라벨은 사용자 낱말로. 약어, 내부 ID, 메타 주석, 범례 과잉 금지.
- 실제 값만. "예시 데이터"를 지어내야 한다면 그 사실을 그림 안에 밝힙니다.
- 팬에 맞게 가로형(폭 900~1200, 높이 폭의 0.5~0.9)으로. 글자 18px 이상.
- 글꼴: `font-family="Apple SD Gothic Neo, Menlo, sans-serif"` (한글).
- 색(어두운 바탕): 배경 `#1e2030`, 글자 `#c8d3f5`, 흐린 글자 `#828bb8`, 강조 파랑 `#3e63a8`, 맞음 초록 `#c3e88d`, 틀림 빨강 `#ff757f`, 주의 노랑 `#ffc777`, 보라 `#c099ff`.

## 3. 명령

```bash
draw show - <<'EOF'
<svg xmlns="http://www.w3.org/2000/svg" width="1000" height="600"> … </svg>
EOF
draw show path/to/file.svg   # 또는 .png
draw close                   # 다 보면 팬 닫기
```

- 같은 탭의 draw 팬을 재사용해 새 그림으로 바꿉니다. 처음엔 nview 팬 아래, 없으면 그림 비율을 보고 현재 팬의 오른쪽·아래 중 그림이 더 크게 보이는 쪽에 포커스를 옮기지 않고 엽니다(크기를 못 읽으면 오른쪽).
- 출력이 `ok <w>x<h> <cols>x<rows>` 면 성공, `ERR …` 면 exit 1 입니다(SVG 문법 오류 포함). 고쳐서 다시 부릅니다.
- 에이전트는 화면을 볼 수 없습니다. 레이아웃이 의심되면 출력 끝의 `view.png` 를 Read 로 열어 직접 확인합니다.
- 팬 맨 아래 줄에 `c 복사` 가 뜹니다. 사용자가 팬을 클릭하고 `c` 를 누르면 그림이 2x PNG 로 클립보드에 복사됩니다(SVG 는 2x 로 다시 렌더, PNG 는 원본). 에이전트가 따로 복사할 필요는 없습니다.
- 응답에는 한 줄로 알립니다. 예: "옆 팬에 화면 vs 저장값 그림을 띄웠습니다." 그림 내용을 채팅에 다시 길게 쓰지 않습니다.
- 그림은 대화용 일회성입니다. 파일은 `$TMPDIR/draw-<탭>` 에 두고 버립니다.

## 구성

- 엔진: `~/dotfiles/scripts/draw` (bash, PATH 에 있음)
- 뷰어: `~/dotfiles/scripts/draw-view` (팬 안에서 돌며 stamp 변경·SIGWINCH 마다 팬 픽셀 크기에 맞춰 1x 로 다시 그림. Rex 는 kitty 이미지를 1x 로 샘플링하므로 2x 는 흐려짐)

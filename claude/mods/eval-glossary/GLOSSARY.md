# Eval 용어 (eval-glossary)

- 응답, 문서, Claude Docs 문서, 아티팩트, PR에서 아래 용어를 쓸 때는 그 글에서 처음 나오는 곳에 괄호로 뜻을 풀어 씁니다. 예: nMAE(교사 총점 대비 정규화 평균 절대 오차). 이후에는 짧게 씁니다.
- 아래 용어를 3개 이상 쓰는 Claude Docs 문서나 리포트에는 앞부분에 「용어」 표(용어 · 뜻)를 두고, 그 글에 쓰인 용어만 넣습니다.
- 정의는 eval 하네스를 따릅니다. 다르게 정의하지 않습니다. 목록에 없는 용어는 평소처럼 풀어 씁니다.

- **A·B·C**: 채점 흐름 3종: A 국어 글쓰기 초3~중3, B 국어 글쓰기 고1~3, C 서논술형
- **C-D**: 서논술형 중 교사가 AI 점수를 수정한 건(불일치 집합). 교사 점수가 정답
- **C-U**: 서논술형 중 교사가 수정하지 않은 건. 일치로 간주하지 않고 drift 감시에만 사용
- **S(참고)**: teacherScore가 AI 점수와 같은 건. 참고 지표로만 보고
- **A0 / A1**: A0 = 운영에 저장된 당시 AI 점수, A1 = eval에서 다시 채점한 점수
- **L0 계약**: 출력 계약 위반: Zod 통과, 항목 수·이름, 점수 범위, 루브릭 허용 집합, band 사이값, 총점 재계산 일치
- **L1 노이즈 플로어**: 같은 입력을 N회(기본 3) 반복 채점했을 때의 흔들림: 총점 SD·최대 편차, flip률
- **L2 변별력**: 원본 vs 규칙 기반 변형(truncate·repeat·noun_stuff·off_topic). 기대: 원본 점수 ≥ 변형 점수
- **L3 교사 (불)일치**: AI 점수와 교사 점수의 차이: nMAE, 방향 편향, 항목 정확·인접 일치, A0 vs A1
- **L4 judge**: LLM judge(gpt-4o-mini)로 점수·피드백 정합과 학년 수준 어휘를 판정
- **nMAE**: 정규화 평균 절대 오차 = |AI 총점 − 교사 총점| ÷ 만점의 평균. 0이면 완전 일치
- **편향**: (AI 총점 − 교사 총점) ÷ 만점의 평균. 음수면 AI가 교사보다 낮게 줌
- **flip률**: 반복 채점 사이에 항목 band(상·중·하)나 루브릭 단계, 성취수준이 바뀐 비율
- **급락**: 같은 글의 최고 반복보다 30pt(만점 대비) 이상 낮게 나온 반복
- **band 사이값**: A·B 항목 점수가 band 경계 사이(31~39, 71~79)에 떨어진 경우. 계약 위반
- **인접 일치**: 항목 점수가 교사와 루브릭 한 단계 이내로 같은 비율(정확 일치보다 느슨함)
- **클래스 bootstrap CI**: 학급 단위로 재표집한 95% 신뢰구간. 같은 학급 글끼리 닮은 점을 반영
- **회귀 후보**: compare.py가 베이스라인 대비 나빠졌다고 표시한 지표. 자동 차단이 아니라 사람 확인 대상
- **drift**: C-U에서 운영 저장 점수(A0)와 재채점 점수(A1)의 차이 ÷ 만점
- **HIL**: human-in-the-loop. 사람이 직접 라벨을 다는 검토 팩
- **QWK**: quadratic weighted kappa. 순서형 점수의 일치도, 큰 차이에 더 큰 벌점
- **SMD**: standardized mean difference. AI와 사람 점수 평균 차이를 표준편차로 나눈 값
- **McNemar 정확검정**: 같은 표본의 두 조건 결과(예: 흔들림 여부)가 엇갈린 건수만으로 차이를 보는 검정
